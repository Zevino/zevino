# Contributing

Thanks for taking an interest in the Zevino profile repository.

Although this repository primarily contains a GitHub profile README and its supporting automation, improvements are welcome.

## What you can improve

- Fix broken or outdated technology badges and image links.
- Improve the README layout, accessibility, and mobile readability.
- Improve the contribution-snake workflow.
- Correct documentation and add useful setup notes.

## Before opening a pull request

1. Keep changes focused and explain the problem they solve.
2. Check that Markdown and HTML snippets render correctly on GitHub.
3. Verify external image and badge URLs are valid.
4. For workflow changes, review the GitHub Actions permissions and inspect the workflow logs.
5. Avoid adding badges, tools, or technologies that do not reflect actual usage.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] README links and image URLs have been checked.
- [ ] Workflow changes have been reviewed for permissions and security.
- [ ] Documentation is updated when needed.

Please include a short summary, the reason for the change, and any relevant screenshots in your pull request.
